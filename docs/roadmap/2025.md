# 2025 Roadmap

Foundational work completed in 2025 to get Crestr from prototype to a functional routing engine and basic web app.

## Achieved

- [x] Initial A* Pathfinding Implementation
- [x] KDTree‑Based Nearest‑Node Lookup
- [x] Basic Graph Construction from OSM Data
- [x] Manual Routing (click‑to‑add waypoints)
- [x] Automatic Routing (Lake District Area)
- [x] Basic Elevation Integration (per‑node or per‑segment)
- [x] Initial Web UI (map, controls, basic layout)
- [x] Basic GPX Export
- [x] Initial Documentation Structure (User + Technical)
- [x] Minor Stability Fixes and Refactors
- [x] Small UX Improvements (labels, tooltips, defaults)
