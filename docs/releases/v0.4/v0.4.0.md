# Release Notes: v0.4.0

This introduces changes included in the following PRs:
- [#146](https://github.com/abdlfc11/Crestr-Hiking-App/pull/146)

## Summary
- Added a mobile-friendly web interface for Crestr so the app is usable on phones and tablets in the absence of a dedicated mobile app
- Replaced the desktop navigation rail and routing actions with compact dropdown menus suited to smaller screens
- Hid map attributions behind a toggleable info button and removed the elevation profile on mobile to free up limited screen space
- Improved touch handling, session behaviour on login, and responsive layouts across auth and main map pages

## Changes

### Mobile interface ([#146](https://github.com/abdlfc11/Crestr-Hiking-App/pull/146))
- Replaced the navigation rail with a dropdown menu toggled by a button in the top left
- Replaced the routing actions menu with a dropdown containing the relevant action buttons
- Removed the elevation profile on mobile, as there is insufficient space to display useful information
- Moved map attributions behind an “i” button that toggles them on and off, since they do not fit on one line on small screens
- Added mobile-safe CSS, touch-action improvements (preventing double-tap zoom on buttons and links), and responsive layouts for the map, auth pages, panels, and saved routes
- Wired mobile login/logout controls and fixed a bug where logging in would delete other existing user sessions
- Added support for accessing the site via a local network address during development
- Included related cleanups such as import cleanup, a success message on save, and preventing saving of routes that contain only a single coordinate

## Why this matters
- A dedicated mobile web interface makes Crestr usable on phones and tablets without requiring a native app, addressing a long-standing gap for users who are out hiking.
- Dropdown-based navigation and actions keep the interface uncluttered on small screens while still providing access to core features.
- Hiding the elevation profile and attributions on mobile prioritises the map itself, which is the most important element when screen space is limited.
- Touch and session fixes improve reliability and reduce friction when using the app on mobile devices.
