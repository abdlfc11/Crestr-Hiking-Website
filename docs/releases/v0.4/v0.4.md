# v0.4 Releases

## Summary

<img src="https://images.crestr.co.uk/Crestr-Mobile-UI.jpeg" width="300" height="200" align="center" alt="Crestr UI during v0.4 development">


The v0.4 release series represents the fourth major iteration of Crestr, focusing primarily on frontend architecture and usability, so that Crestr
becomes an app that people, including myself, can reliably use as a planning tool. 

## Notable Changes

- Implemented a mobile implementation of Crestr so that users can plan routes on the go, as opposed to prior when users were locked out of mobile
route planning
