# v0.2 Releases

## Summary

![Crestr UI during v0.2 development](https://images.crestr.co.uk/crestr-v2.png)

The v0.2 release series represents the second major iteration of Crestr, introducing significant changes across the routing engine, backend architecture, user interface, and developer experience.

Across v0.2.0–v0.2.12, the project moved toward a faster and more maintainable architecture while reducing friction for users creating and planning routes.

## Notable Changes

- Migrated the backend from Flask to FastAPI, providing a stronger foundation for asynchronous functionality and future API development.
- Migrated the graph-processing framework from NetworkX to igraph, reducing routing times to approximately 50 ms for typical 5–10 km routes.
- Added account-free route creation, allowing users to try Crestr without first creating an account.
- Improved route statistics and ETA calculations, including the integration of Naismith's Rule.
- Improved error handling, keyboard navigation, accessibility, and general UI behaviour across the application.
