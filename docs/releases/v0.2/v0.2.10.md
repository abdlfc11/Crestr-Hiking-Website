# Release Notes: v0.2.10

This merges changes included in the following PRs:  

- [#93](https://github.com/abdlfc11/Crestr-Hiking-App/pull/93) 
- [#95](https://github.com/abdlfc11/Crestr-Hiking-App/pull/95) 
- [#97](https://github.com/abdlfc11/Crestr-Hiking-App/pull/97) 

## Summary
Migrated core frontend libraries (OpenLayers, Driver.js, Chart.js, Lucide) from CDN scripts to npm packages managed by Vite for reproducible offline builds, replaced the collapsible nav rail with a persistent always-visible rail that expands on hover, and introduced a donate modal offering Liberapay and Ko-fi options while removing the previous “donations closed” state. Also fixed an elevation-profile chart breakage that occurred when switching themes during manual routing.

## Changes

### Vite build & npm package migration ([#93](https://github.com/abdlfc11/Crestr-Hiking-App/pull/93))
- Converted OpenLayers, Driver.js, Chart.js and Lucide from CDN `<script>` includes to npm packages imported via ES modules.
- Added a full Vite build pipeline; Docker now copies the built frontend assets into the Python image.
- Removed the unused `vite_asset` FastAPI route (no longer needed once assets are bundled).
- Updated the deprecated `rollUpOptions` key to `rollDownOptions` in the Vite config.
- Fixed a bug where changing the theme while in manual routing mode broke the elevation-profile chart rendering.
- Updated dark-mode Chart.js colours to match the new import setup.

### Persistent hover-expanding nav rail ([#95](https://github.com/abdlfc11/Crestr-Hiking-App/pull/95))
- Replaced the previous collapsible/toggle nav rail with a rail that is always present and expands automatically on hover (or focus).
- Updated layout, spacing and map-panel offsets so the map and side panels correctly reflow when the rail expands/collapses.
- Removed open/close navigation handlers and the exported `closeNav` API; panels now only close themselves.
- Updated tour targets and theme variables so guided tours correctly describe the new rail.
- Re-confirmed the elevation-profile chart theme-switch fix in the context of the new layout.

### Donate modal with Liberapay & Ko-fi ([#97](https://github.com/abdlfc11/Crestr-Hiking-App/pull/97) )
- Replaced the disabled “still in Beta, donations closed” tooltip on the donate link with a proper modal.
- Modal presents Liberapay and Ko-fi as donation options and follows the existing `.modal-overlay` / `.modal-content` pattern.
- Added `donate-modal.css` for layout, cards, icons, focus/hover/active states, plus light/dark theme support.
- Wired open/close behaviour (× button, “Maybe later”, backdrop click, Escape) and registered the new Lucide icons.

## Why this matters
- Moving libraries off CDNs gives deterministic builds, offline capability and removes a runtime dependency on third-party uptime.
- A persistent, hover-expanding nav rail removes an extra interaction step and keeps navigation always discoverable.
- Opening donations via a clean modal lets supporters contribute through familiar platforms while keeping the UI consistent with the rest of the app.
- The elevation-profile chart no longer breaks when users switch themes mid-route, improving reliability in manual routing mode.
