# Release Notes: v0.2.12
This introduces changes included in the following PRs:

- [#108](https://github.com/abdlfc11/Crestr-Hiking-App/pull/108)
- [#110](https://github.com/abdlfc11/Crestr-Hiking-App/pull/110)
- [#112](https://github.com/abdlfc11/Crestr-Hiking-App/pull/112)
- [#113](https://github.com/abdlfc11/Crestr-Hiking-App/pull/113)
- [#115](https://github.com/abdlfc11/Crestr-Hiking-App/pull/115)

## Summary
- Fixed regressions from `v0.2.11` around cached/imported routes, elevation display, and loading animations, while integrating Naismith’s Rule for more accurate ETAs on both auto and manual routes
- Extended Naismith’s Rule consistency to manual routing via a new `/routing/normalise-route-stats` endpoint so auto, manual, and saved-route ETAs all use the same calculation
- Added keyboard navigation shortcuts and a dedicated Shortcuts modal, reorganised the lower nav rail, and polished related styling/accessibility
- Improved error handling across routing, import, and save flows by separating technical log messages from user-facing toasts, raised the routing API rate limit, and prevented the home button from interrupting in-progress map animations

## Changes
### Bug fixes & Naismith ETA improvements ([#108](https://github.com/abdlfc11/Crestr-Hiking-App/pull/108))
- Resolved errors when displaying cached routes (incorrect stats-object references)
- Switched URL redirects to relative paths
- Updated secondary button colours for visual consistency
- Fixed generate-path button loading animation centring
- Handled route imports that lack elevation data without errors
- Display “No Data” instead of “+0 m” when elevation is missing
- Integrated the Naismith helper into route calculation and route saving for more accurate ETAs

### Naismith’s Rule for manual routing ([#110](https://github.com/abdlfc11/Crestr-Hiking-App/pull/110))
- Refined the Naismith helper in `Routes/helpers.py`
- Added `/routing/normalise-route-stats` endpoint (with `NormaliseRouteModel`) that returns distance, elevation, and Naismith-based ETA for an arbitrary coordinate path
- Manual routing now calls the new endpoint so its stats match auto-routing and saved-route ETAs
- Cleaned up unnecessary `console.log` statements in the client

### Navigation shortcuts & Shortcuts modal ([#112](https://github.com/abdlfc11/Crestr-Hiking-App/pull/112), [#113](https://github.com/abdlfc11/Crestr-Hiking-App/pull/113))
- Added keyboard shortcuts for faster navigation and mode switching, organised into maintainable helper functions
- Introduced a Shortcuts modal (with dedicated styles) that lists available shortcuts
- Moved utility controls and modals to the lower half of the navigation rail alongside login/logout
- Minor token and donate-modal SVG colour updates for theme consistency
- Follow-up fixes for modal coordination, `showModal()` usage, accessibility (aria-labelledby), and replacing non-semantic `<a>` tags with `<button>` elements

### Improved error handling ([#115](https://github.com/abdlfc11/Crestr-Hiking-App/pull/115))
- Errors now carry a technical message (for logs) and a separate `cause` (friendly user-facing string)
- FastAPI routing endpoints return both `message` and `user_message`
- Hardened route-import error handling so malformed files surface clear feedback
- Auto-routing toasts now show the specific `error.cause` instead of a generic string
- Raised the routing API rate limit to reduce false-positive throttling
- Home button now no-ops while the map is animating, preventing broken UI resets

## Why this matters
- Cleaning up v0.2.11 regressions restores reliable cached-route loading, elevation display, and button behaviour while giving users more realistic hiking times via Naismith’s Rule everywhere.
- Consistent Naismith ETAs across auto, manual, and saved routes remove confusing discrepancies and make the stats panel trustworthy.
- Keyboard shortcuts and the Shortcuts modal speed up everyday workflows and make the app’s capabilities discoverable.
- Structured error handling turns opaque failures into clear, actionable toasts; the higher rate limit and animation guard further reduce friction during normal use.
