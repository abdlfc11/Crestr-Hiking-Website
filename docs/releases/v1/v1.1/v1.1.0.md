- [#169](https://github.com/abdlfc11/Crestr-Hiking-App/pull/169)

## Summary

- Removed the unused `shapes` directory and updated OpenLayers to 10.11.0
- Added the ability to insert intermediary points into manual routes by dragging from the route line
- Fixed the save-route toggle so it no longer appears transparent on hover
- Split the large `ui.ts` file into focused modules for improved maintainability
- Added an update-alert system that notifies existing users of new releases and links to the changelog

## Changes

### Remove shapes directory and update OpenLayers ([#169](https://github.com/abdlfc11/Crestr-Hiking-App/pull/169))

- Updated the OpenLayers dependency from `^10.10.0` to `^10.11.0`
- Deleted the unused `shapes` directory (and associated shapefile metadata) that was previously used when generating custom graphs, reducing repository size by ~150 MB

### Enhanced route editing ([#170](https://github.com/abdlfc11/Crestr-Hiking-App/pull/170))

- Added a pointer interaction that lets users drag from an existing manual route line to insert a new intermediary waypoint
- Shows a placeholder point while dragging and inserts the point in the correct segment order on release
- Updated cursor behaviour (pointer over saved points, grab over route features)
- Improved segment-cache handling, drag-threshold checks, and promise error handling so successive edits stay consistent

### Save-route toggle background ([#171](https://github.com/abdlfc11/Crestr-Hiking-App/pull/171))

- Removed the unused `--glass-bg` CSS token and the associated hover background rule that caused the save-route toggle to appear transparent after the glassmorphism styles were retired

### Modularise UI code ([#173](https://github.com/abdlfc11/Crestr-Hiking-App/pull/173))

- Split the monolithic `ui.ts` into dedicated modules: `ui-mobile.ts`, `ui-modals.ts`, `ui-panels.ts`, `ui-routing.ts`, `ui-tours.ts`, and `ui-initialisation.ts`
- Updated imports and initialisation so the application continues to behave identically while being easier to navigate and extend
- Added immediate error-toast feedback when an invalid file is selected during route import

### Update alerts for users ([#174](https://github.com/abdlfc11/Crestr-Hiking-App/pull/174))

- Introduced `ui-updates.ts` that fetches the latest release data and compares it against localStorage markers
- Displays a modal to existing users (using prior tour or access flags) when a new version is available, with a direct link to the changelog
- Normalised tour localStorage values to lowercase `"true"` for consistency and reliable detection of returning users
- Ensured new users are not shown the update modal and that localStorage failures do not block navigation to the changelog

## Why this matters

- Removing the obsolete shapes data and updating OpenLayers keeps the project lean and current without affecting functionality.
- Drag-to-insert route editing removes the need to repeatedly undo and re-plot long routes, making manual planning significantly faster and less error-prone.
- The save-route toggle fix restores expected visual feedback and eliminates a confusing transparent state on hover.
- Breaking `ui.ts` into focused modules improves code clarity and development speed as the codebase continues to grow.
- The new update-alert system ensures existing users are promptly informed of new features (especially those announced elsewhere) and can jump straight to the relevant changelog, improving discovery and reducing support friction.
