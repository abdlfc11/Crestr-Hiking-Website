# v1.0 Releases

The v1.1 release series brings many features and improvements to Crestr, for both users and developers, including enhanced route editing, a modularisation of a 2000+ line UI file and alerts for existing users for new versions of Crestr. 

## Notable Changes

- Modularised the `ui.ts` file logically into multiple files, examples of such files include `ui-routing.ts`, `ui-panels.ts` and `ui-modals.ts` amongst others, speeding up development and improving the readability and clarity of the codebase
- Removed unnecessary `shapes/` directory, freeing 150MB+ of space and removing ambiguity regarding the presence of the folder 
- Added a simple but effective system of alerting users of new versions of Crestr via the custom modal template already used in the app, allowing users to either passively acknowledge it or visit the changelogs for more details
