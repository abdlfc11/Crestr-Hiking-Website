# Release Notes: v1.0.1

This release introduces the changes included in the following pull request:

- [#163](https://github.com/abdlfc11/Crestr-Hiking-App/pull/163)

## Summary

- Fixed mobile interface interactions by removing duplicated HTML elements that prevented event listeners from functioning correctly.

## ## Changes

### Mobile Interface Regression ([#163](https://github.com/abdlfc11/Crestr-Hiking-App/pull/163))

- Removed duplicated HTML markup for mobile-specific interface elements, introduced during a previous branch merge.
- Corrected event listener associations to ensure that interactive elements respond to user input as expected.
- Restored access to essential routing controls, including undo, redo and clear route.
- Restored navigation panel functionality, allowing users to access other application sections, including route importing, saved routes and settings.

## Why This Matters

- **Improved mobile functionality:** Users can access essential routing controls and application features on mobile devices.
- **Improved reliability:** Resolving the underlying DOM interaction issues ensures that visible interface elements respond correctly to user interactions.
- **Cross-device consistency:** Restores functionality that was previously available on desktop but inaccessible on mobile devices.
