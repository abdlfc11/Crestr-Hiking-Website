# v1 Releases

## Summary

<img src="https://images.crestr.co.uk/v1.0.0-release-image.jpeg" align="center" alt="Crestr UI during v0.4 development">


The v1 release series represents the first stable version of Crestr, focusing primarily on integrating the BRouter routing engine as well as making the app one that people can use reliably to create accurate routes.  

## Notable Changes

- Integrated BRouter as the routing engine, replacing the custom routing engine used previously, allowing for expansion to the UK and Ireland 
- Updated [driver.js](https://driverjs.com) tours to reflect current desktop UI and the new Mobile UI
- Removed glassmorphism backgrounds for most panels, leaving only the mobile attribution background with a glassmorphism background to ensure visual consistency and less distraction when making routes
