# v0.1 Releases

## Summary

This release series introduced Crestr to the public for the first time, establishing the core functionality and architecture of the application.

Development during v0.1 focused on building the foundations of Crestr as a hiking route planner,
including automatic and manual routing, route statistics, saved routes and points, and support for importing and exporting route data.

## Notable Changes

- Introduced automatic route generation using A* pathfinding over OpenStreetMap data.
- Added manual route creation for greater control over planned routes.
- Added route statistics, including distance, estimated time, and elevation change.
- Introduced saved routes and points for registered users.
- Added support for importing and exporting common route formats, including GPX and GeoJSON.
- Established the initial Flask backend and web-based mapping interface.
- Introduced user accounts and authentication.
- Deployed Crestr publicly, making the application available outside of the development environment.
