## Summary

Completed the full migration of Crestr from Flask to FastAPI, replaced circular markers for saved points with clearer SVG pin icons, and resolved a series of post-refactor bugs (incorrect imports, missing guards, session/auth mismatches, error handling, and timezone support) to restore reliable authentication, routing, point management, and file import behaviour.

## Changes

### Visual improvement: saved points in `static/js/saved_points/style.js` ([#73](https://github.com/abdlfc11/Crestr-Hiking-App/pull/73))

- Added `createPinSVG()` helper that generates an SVG pin icon.
- Introduced colour constants (`TEXT_STROKE`, `TEXT_FILL`, `SELECTED_FILL`) for easy theme experimentation.
- Replaced OpenLayers circle markers with the new SVG pins for both selected and unselected states, including proper anchors, scaling and label styling.

### Major refactor: Flask → FastAPI ([#74](https://github.com/abdlfc11/Crestr-Hiking-App/pull/74))

- Converted all backend routes (auth, points, routes/pathfinding, settings, search, report-issue, error-logging) to FastAPI routers with Pydantic models and proper dependency injection.
- Introduced session-based authentication (Sessions table) and removed the old Flask-Session machinery.
- Reorganised frontend utilities into `static/js/utils/` (style-utils, format-utils, ui-utils, etc.).
- Updated templates, static asset loading (`path=` instead of `filename=`), `window.appConfig` endpoint paths, and Gunicorn config to use Uvicorn workers.
- Added database migrations for cascading deletes, indexes, timestamp defaults and session storage.
- Cleaned up environment configuration and Docker Compose for the new FastAPI runtime.

### Bug fixes & polish after the refactor ([#75](https://github.com/abdlfc11/Crestr-Hiking-App/pull/75))

- Fixed incorrect imports (e.g. `auth.js` in `ui.js`), NameErrors, and remaining Flask-style patterns.
- Added guard clauses against `None` values for users/points, safer error handling and `escapeHTML()` for user-controlled content.
- Corrected form-data / JSON body handling, exception re-raising, duration type (int), and timezone-aware timestamps in PostgreSQL.
- Improved route-import validation (max file size, successful logging), KML parsing, and search request timeouts.
- Updated `map.html` to use backend-passed user variables instead of the old Flask session.
- Bumped `python-multipart`, added a reload-mode Uvicorn command, and aligned example.env credentials.

## Why this matters

- The FastAPI migration unlocks asynchronous routes and a cleaner, more maintainable backend architecture.
- SVG pins make saved points far easier to spot on the map.
- The follow-up fixes eliminate runtime errors that appeared after the large refactor, restoring a stable login/logout flow, point CRUD, route import/save, and error reporting.
