# v0.3 Releases

## Summary

![Crestr UI during v0.3 development](https://images.crestr.co.uk/Main-UI.jpeg)

The v0.3 release series represents the third major iteration of Crestr, focusing primarily on frontend architecture, route interaction, and usability.

This release series simplifies the route-planning workflow while improving the maintainability and type safety of the frontend codebase.

## Notable Changes

- Migrated the JavaScript codebase to TypeScript, improving type safety, debugging, and developer experience.
- Introduced route editing, allowing users to modify existing routes.
- Unified automatic and manual routing into a single routing mode, simplifying the route-planning workflow.
- Added a map context menu for actions such as saving specific points and copying coordinates.
