# Release Notes: v0.3.0

This introduces changes included in the following PRs:

- [#118](https://github.com/abdlfc11/Crestr-Hiking-App/pull/118)
- [#121](https://github.com/abdlfc11/Crestr-Hiking-App/pull/121)
- [#123](https://github.com/abdlfc11/Crestr-Hiking-App/pull/123)


## Summary

- Added a new keyboard shortcut for resetting the map view, integrating it with the existing home-button behaviour and documenting it in the Shortcuts dialog
- Prevented empty search attempts from being submitted, avoiding unnecessary or invalid search requests
- Merged the separate auto and manual routing modes into a unified routing experience, simplifying how users interact with route creation
- Polished supporting UI behaviour and styling, including home-button panel/modal handling and clearer tooltips with solid backgrounds and constrained text wrapping

## Changes

### Reset view keyboard shortcut ([#118](https://github.com/abdlfc11/Crestr-Hiking-App/pull/118))

- Added a keyboard shortcut for resetting the map to its default view
- Reused the existing home-button behaviour so keyboard and button interactions follow the same reset flow
- Added the new reset-view shortcut to the Shortcuts dialog
- Reordered panel-closing and modal-closing calls in the home-button flow for cleaner UI state handling
- Removed a duplicated `#region` marker as part of the related cleanup

### Empty search guard ([#121](https://github.com/abdlfc11/Crestr-Hiking-App/pull/121))

- Added a guard against empty search attempts
- Prevents search logic from running when no usable query has been entered
- Reduces unnecessary requests and avoids confusing behaviour from blank searches

### Unified auto and manual routing ([#123](https://github.com/abdlfc11/Crestr-Hiking-App/pull/123))

- Merged the previously separate auto and manual routing modes
- Simplified the routing workflow so route creation no longer depends on switching between two distinct modes
- Consolidated related routing interactions around a single route-building experience
- Reduced UI and state-management complexity associated with maintaining separate routing modes

### Tooltip styling improvements

- Updated tooltips to use a solid background for improved readability
- Added a maximum width and text wrapping so longer tooltip content remains contained and readable

## Why this matters

- The reset-view shortcut makes a common map action faster while keeping keyboard behaviour consistent with the existing home button.
- Blocking empty searches removes an unnecessary failure path and makes search interactions more predictable.
- Unifying auto and manual routing removes a major distinction from the route-building workflow, reducing mode switching and making routing simpler to understand and maintain.
- The tooltip changes improve readability and prevent longer help text from producing awkward or oversized UI elements.
