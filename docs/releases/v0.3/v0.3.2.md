# Release Notes: v0.3.2

This introduces changes included in the following PRs:
- [#133](https://github.com/abdlfc11/Crestr-Hiking-App/pull/133)
- [#135](https://github.com/abdlfc11/Crestr-Hiking-App/pull/135)
- [#138](https://github.com/abdlfc11/Crestr-Hiking-App/pull/138)
- [#140](https://github.com/abdlfc11/Crestr-Hiking-App/pull/140)
- [#143](https://github.com/abdlfc11/Crestr-Hiking-App/pull/143)
- [#144](https://github.com/abdlfc11/Crestr-Hiking-App/pull/144)

## Summary
- Fixed several issues in the saved routes dashboard, including the create-route button becoming unresponsive after deleting all routes and inconsistencies between initially rendered and dynamically added route entries
- Resolved incorrect elevation chart theming when switching between dark and system themes, and improved theme resolution more generally
- Redesigned the saved routes dashboard from a card layout to a more familiar and extensible list layout with an options menu
- Added route sharing so users can share routes via link or QR code, including with people who do not have a Crestr account
- Simplified and made more consistent the map animation used when loading a route

## Changes

### Saved routes dashboard bug fixes ([#133](https://github.com/abdlfc11/Crestr-Hiking-App/pull/133), [#140](https://github.com/abdlfc11/Crestr-Hiking-App/pull/140))
- Re-initialised the event listener on the “create a route” button after the last saved route is deleted, so the button continues to work without a page refresh
- Ensured routes added dynamically (after saving) use the same structure and styling as routes rendered on initial page load
- Initialised Lucide icons when route rows are inserted dynamically so newly saved routes display correctly

### Elevation chart and theme handling ([#135](https://github.com/abdlfc11/Crestr-Hiking-App/pull/135))
- Updated theme resolution so `getTheme()` always returns a concrete `light` or `dark` value instead of `system`
- Fixed the elevation chart so it renders with the correct theme when the user switches from dark mode to the system theme while the app is already in dark mode
- Removed an unused import as part of the cleanup

### Saved routes dashboard redesign ([#138](https://github.com/abdlfc11/Crestr-Hiking-App/pull/138))
- Replaced the card-based saved routes layout with a list-style layout that is more familiar to users and easier to extend
- Moved route actions into an options menu (instead of placing multiple buttons directly on each card)
- Updated related styles, tokens, and empty-state handling, and improved menu behaviour (closing other menus, dismissing on outside click or Escape, and restoring focus)

### Route sharing ([#143](https://github.com/abdlfc11/Crestr-Hiking-App/pull/143))
- Added the ability to share a saved route via a link (copied to the clipboard) or a QR code shown in a modal
- Implemented backend support (database table, migrations, and API endpoints) for creating, storing, and retrieving shared routes
- Added frontend support for generating share links, displaying the QR code, and loading a shared route from a `route_id` query parameter (works for both logged-in and guest users)
- Fixed a related bug where elevation profiles on loaded and shared routes could disappear when changing the app theme

### Load route map animation ([#144](https://github.com/abdlfc11/Crestr-Hiking-App/pull/144))
- Removed the previous conditional zooming behaviour when loading a route
- Replaced it with a single, consistent smooth fit-to-route animation that works the same way regardless of the current map zoom or position

## Why this matters
- The saved routes dashboard fixes remove confusing or broken states that could appear after deleting routes or saving new ones, making everyday route management more reliable.
- Correct theme handling for the elevation chart prevents hard-to-read charts when users change themes, improving overall visual consistency.
- The list-style dashboard redesign makes the interface more familiar and creates space for new actions (such as sharing) without cluttering each route entry.
- Route sharing is a long-requested feature that lets users easily send routes to friends or collaborators, including people who do not yet have an account.
- The simplified load-route animation removes unpredictable zoom behaviour and gives a smoother, more predictable experience when opening a route on the map.
