## Summary

The following pages detail my custom pathfinding and graph building processes used in Crestr before it was replaced by a BRouter service. 

Crestr moved to a BRouter service for routing in [v1.0.0](../../releases/v1/v1.0/v1.0.0.md), the last version of Crestr before this change is [v0.4.0](../../releases/v0.4/v0.4.0.md), and can be found in the [Legacy Crestr Repository](https://github.com/abdlfc11/Crestr-Legacy).
